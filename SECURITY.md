# Security Policy

# Scope & Design
Mini-Obsidian is an offline, local-first academic desktop utility. 
All note contents and SQLite indices are stored strictly on the local filesystem.
No network connections, telemetry, or external credentials are used.
Prepared SQL statements are used across NoteStore to ensure database query safety.

# Reporting Issues
To report bugs or security concerns, open an issue directly on the GitHub project repository with steps to reproduce.
